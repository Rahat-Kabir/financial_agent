# 📊 AI-Powered Stock Analysis App  

An advanced stock analysis application powered by OpenAI's GPT-4 and real-time market data from YFinance. This tool allows users to compare stocks, analyze trends, and get AI-driven investment insights.  

## 🚀 Features  
- **Stock Comparison**: Compare two stocks based on price, fundamentals, and market sentiment.  
- **Single Stock Analysis**: Get insights on stock price trends, analyst recommendations, and recent news.  
- **Real-Time Data**: Uses YFinance tools to fetch live stock market data.  
- **AI-Powered Insights**: Generates reports using OpenAI's GPT-4.
